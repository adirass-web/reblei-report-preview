About United States Courts Opinions

What are United States Courts Opinions?

United States Courts Opinions (USCOURTS) collection is a collaborative effort between the U.S. Government Publishing Office (GPO) and the Administrative Office of the United States Courts (AOUSC) to provide public access to opinions from selected United States appellate, district, and bankruptcy courts. The content of this collection dates back, generally, to 2004, though searchable electronic holdings for some courts may be incomplete for this earlier time period. In addition, there may be older historical opinions available in GovInfo on a select and non-comprehensive basis.

The secure transfer of files to GPO from the AOUSC maintains the chain of custody, allowing GPO to authenticate the files with digital signatures.

How are they organized?

Once an opinion is located, all associated opinions within the same case can be accessed from the opinion's Details page.

What's available?

Opinions from selected United States appellate, district, and bankruptcy courts are made publicly available in the USCOURTS collection. Opinions from select National courts, such as the Court of International Trade, Court of Federal Claims, and Judicial Panel on Multidistrict Litigation are also available in this collection.

Have a question about a posted opinion?

The posting of Federal court opinions is consistent with the E-Government Act's requirement for the substance of all written opinions, issued after April 16, 2005, to be made available in a text searchable format. [Pub. L. No. 107-347, Title II, Section 205].

GPO hosts the United States Courts Opinions collection on behalf of the U.S. Courts, and GPO, can only remove an opinion at the direction of the court. If you have questions about content in the United States Courts Opinions collection, please contact the AOUSC.


Searching United States Courts Opinions

You can find United States Courts Opinions by:

  • Using Basic Search for keyword and metadata fielded searches,
  • Using Advanced Search; fields specific to the U.S. Courts Opinions collection will display after you select U.S. Courts Opinions in the Refine by Collection column,
  • Refining search results by clicking on links in the Refine Your Search panel on the left hand side of the page (the sections under Refine Your Search correspond to the metadata available for the documents), and
  • Browsing the U.S. Courts Opinions browse page.

General GovInfo Search Tips

Search Examples

Search by Court Type For example, District Court opinions.

  • Using Basic Search, enter: collection:uscourts courttype:district
  • Using Advanced Search, select United States Courts Opinions under Refine by Collection, then under Search In, select Court Type from the first box and select District from the next box

Search by Court Name For example, United States Bankruptcy Court Southern District of Florida.

  • Using Basic Search, enter: collection:uscourts courtname:"United States Bankruptcy Court Southern District of Florida"
  • Using Advanced Search, select United States Courts Opinions under Refine by Collection, then under Search In, select Court Name from the first box and select United States Bankruptcy Court Southern District of Florida from the next box

Search by Title For example, opinions with "hatch" in the title.

  • Using Basic Search, enter: collection:uscourts title:hatch
  • Using Advanced Search, select United States Courts Opinions under Refine by Collection, then under Search In, select Title from the first box and enter hatch in the next box

Search by Case Number For example, opinions with "1:01-bk-13984" as the Case Number.

  • Using Basic Search, enter: collection:uscourts casenumber:(1:01-bk-13984)
  • Using Advanced Search, select United States Courts Opinions under Refine by Collection, then under Search In, select Case Number from the first box and enter 1:01-bk-13984 in the next box

Search by Party Name For example, opinions with "hatch" as one of the party names.

  • Using Basic Search, enter: collection:uscourts partyname:hatch
  • Using Advanced Search, select United States Courts Opinions under Refine by Collection, then under Search In, select Party Name from the first box and enter hatch in the next box

Search by Docket Text For example, opinions with "judge lisi" in the docket text.

  • Using Basic Search, enter: collection:uscourts dockettext:(judge lisi)
  • Using Advanced Search, select United States Courts Opinions under Refine by Collection, then under Search In, select Docket Text from the first box and enter judge lisi in the next box

Sample United States Courts Opinions URLs

GovInfo uses two key pieces of information to construct predictable URLs to documents and the Details pages. The Package ID is used to identify an individual case in the United States Courts Opinions collection. The Granule ID is used to identify individual opinions within each case.

Identifier

Structure/Metadata Field

Examples

Package ID

USCOURTS-{Court Code}-{Case Number}

 

Note:Any colons (:) in the Case Number are converted to underscores (_).

USCOURTS-meb-2_10-ap-02064

Granule ID

{Package ID}-{Sequence Number}

USCOURTS-meb-2_10-ap-02064-0

See list of Court Codes

Details Page for a Case

Structure: https://www.govinfo.gov/app/details/{Package ID}

Example: https://www.govinfo.gov/app/details/USCOURTS-meb-2_10-ap-02064

 

Details Page for an Opinion

Structure: https://www.govinfo.gov/app/details/{Package ID}/{Granule ID}

Example:  https://www.govinfo.gov/app/details/USCOURTS-meb-2_10-ap-02064/USCOURTS-meb-2_10-ap-02064-0  

 

PDF File for an Opinion

Structure: https://www.govinfo.gov/content/pkg/{Package ID}/pdf/{Granule ID}.pdf

Example:  https://www.govinfo.gov/content/pkg/USCOURTS-meb-2_10-ap-02064/pdf/USCOURTS-meb-2_10-ap-02064-0.pdf

  • Display on Details Pages.

See below for information on how these case numbers have been converted for each type of court. The user readable version is displayed on GovInfo, however users can search by either value using the Case Number advanced search field or the casenumber: field operator.
